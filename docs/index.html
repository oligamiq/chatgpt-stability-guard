Stability Guard for ChatGPT プライバシーポリシー

最終更新日: 2026年8月15日

Stability Guard for ChatGPT は独立した非公式のブラウザ拡張機能であり、OpenAIによる作成、承認、提携製品ではありません。

1. 本拡張機能が処理するデータ

ChatGPT上のWebサイトコンテンツおよび個人的コミュニケーション

本拡張機能は、https://chatgpt.com/* 上に表示されたDOMをブラウザ内で読み取り、会話ターン、Thinking / reasoning、tool trace、埋め込みツールUI、プレースホルダー、code / log、エラー表示などを識別します。

このDOMには、ChatGPTとの会話などの個人的コミュニケーションや、ユーザーが入力したWebサイトコンテンツが含まれる場合があります。これらは、描画負荷を減らし、ユーザーが選択したChatGPT UI要素を非表示または遅延描画するという本拡張機能の単一目的のために、端末上で一時的に処理されます。

本拡張機能は、会話内容やWebサイトコンテンツを独自の永続ストレージへ保存せず、開発者または第三者のサーバーへ送信しません。

ローカル設定

本拡張機能は chrome.storage.local を使用して、各機能の有効・無効、表示する直近の会話数、UI言語などの設定をブラウザ内に保存します。これらの設定は開発者運営サーバーへ送信されません。

2. 外部通信とリモートコード

本拡張機能には、解析、広告、テレメトリ、リモート設定、アカウントシステム、開発者運営バックエンドはありません。本拡張機能自身からユーザーデータを外部へ送信するネットワークリクエストを開始しません。

実行するJavaScriptは拡張機能パッケージ内に同梱されており、外部サーバーやCDNからリモートコードを取得して実行しません。

3. データの販売・共有・その他の利用

本拡張機能はユーザーデータを販売、共有、第三者へ転送しません。また、広告、信用評価、融資、または本拡張機能の単一目的と関係のない用途にユーザーデータを使用しません。

4. ストアのデータ利用要件

本拡張機能は、配布先ストアで要求されるユーザーデータ保護・限定利用の要件に従い、上記の単一目的以外にユーザーデータを利用しません。

5. 保持と削除

ChatGPT上のWebサイトコンテンツや会話内容は、表示中のページ内で一時的に処理されるだけで、本拡張機能によって保持されません。ローカル設定は、ユーザーが変更・消去するか、本拡張機能を削除するまでブラウザプロファイル内に保持されます。

6. 権限

storage 権限はローカル設定を保存するために使用します。ホストアクセスおよびcontent scriptは https://chatgpt.com/* のみに限定し、上記の表示最適化を行うために使用します。

7. 互換性

本拡張機能は現在のChatGPT Web UIに合わせて実装されています。ChatGPT側のDOMまたはUI更新により、拡張機能が更新されるまで一時的に検出や非表示が機能しなくなる場合があります。

8. お問い合わせ

プライバシーに関する質問は、拡張機能のストア掲載ページに表示される開発者連絡先をご利用ください。

Privacy Policy — Stability Guard for ChatGPT

Last updated: August 15, 2026

Stability Guard for ChatGPT is an independent, unofficial browser extension and is not created by, endorsed by, or affiliated with OpenAI.

1. Data handled by the extension

Website content and personal communications on ChatGPT

The extension locally reads the rendered DOM on https://chatgpt.com/* to identify conversation turns, Thinking / reasoning displays, tool traces, embedded tool UI, placeholders, code / log blocks, and error displays.

This DOM may contain personal communications such as conversations with ChatGPT and website content entered by the user. This content is processed transiently on the user's device solely for the extension's single purpose: reducing rendering churn and optionally hiding or deferring selected ChatGPT UI elements.

The extension does not persist conversation content or website content in its own storage and does not transmit that content to the developer or to third-party servers.

Local settings

The extension uses chrome.storage.local to store settings such as enabled features, the number of recent conversation exchanges to display, and the UI language. These settings are not transmitted to a developer-operated server.

2. Network activity and remote code

The extension has no analytics, advertising, telemetry, remote configuration, account system, or developer-operated backend. It does not initiate network requests that transmit user data externally.

All JavaScript executed by the extension is packaged with the extension. It does not download or execute remote code from external servers or CDNs.

3. Sale, sharing, and other use of data

The extension does not sell, share, or transfer user data to third parties. User data is not used for advertising, creditworthiness, lending, or purposes unrelated to the extension's single purpose.

4. Store data-use requirements

The extension follows the user-data protection and limited-use requirements of its distribution stores and does not use user data for purposes outside the single purpose described above.

5. Retention and deletion

Website content and conversations on ChatGPT are processed transiently in the displayed page and are not retained by the extension. Local settings remain in the browser profile until changed, cleared, or the extension is removed.

6. Permissions

The storage permission is used for local settings. Host access and content scripts are limited to https://chatgpt.com/* and are used only to provide the display optimizations described above.

7. Compatibility

The extension is implemented against the current ChatGPT web UI. Changes to ChatGPT's DOM or UI can temporarily break detection or hiding until the extension is updated.

8. Contact

For privacy questions, use the developer contact method shown on the extension's store listing.

# Chrome Web Store listing — 日本語

## タイトル
Stability Guard for ChatGPT

## 1行説明
長大なChatGPT会話の重さと表示の混雑を軽減。古いターン、Thinking、ツールUI、古いエラーなどを端末内だけで選択的に抑制します。

## 詳細説明
長いChatGPT会話では、古いターン、Thinking / reasoning、ツール履歴、埋め込みApp、エラー、code / logなどが積み重なり、スクロールや描画が重くなったり画面が混雑したりします。Stability Guard for ChatGPT は、それらの描画負荷を端末内だけで抑え、ChatGPT上の会話履歴そのものは削除しません。

処理は `chatgpt.com` 上のブラウザ内だけで完結します。会話内容の外部送信、広告、解析、テレメトリ、開発者バックエンド、リモート設定、リモートコードはありません。

主な機能:
- 直近N回を常時表示し、それ以前の対話をアコーディオンに折りたたむ（任意・既定OFF、Nの既定値は3）
- Thinking / reasoning 表示を非表示
- MCP / tool trace本体と `Called tool` / 「ツールが呼び出されました」等の概要UIを非表示
- 動作中のApp、Connect、認証、Retryなどの操作UIは親ごと消さず保護
- `Failed to fetch template` 等の古いApp読込エラーだけを非表示し、現在ターンのエラーは表示
- 壊れたことを確認できた小さなAppプレビュー残骸を抑制し、正常または読込中のAppは維持
- rich UI読込中プレースホルダをプリハイド
- 長いtraceの低コントラスト化・高さ制限
- 画面外のcode / logや古い会話ターンを必要に応じて遅延描画
- 現在の非表示・遅延描画件数を表示
- 各最適化を個別にON/OFF

recent-NアコーディオンはChatGPTの仮想スクロールを考慮して動作します。折りたたみ中は直近N件のsemantic boundaryを維持し、過去履歴を展開すると通常スクロールへ戻ります。再び折りたたむ際は境界を再取得し、branch編集や大きな仮想スクロール構造変更で安全な境界を確定できない場合はrecent-Nだけfail-openします。

### 互換性について
この拡張は現在のChatGPT Web UIのDOM/属性構造に合わせて実装されています。ChatGPT側のサイト更新でDOMやUI構造が変わると、拡張の更新が提供されるまで検出・非表示・プレースホルダ抑制の一部または全部が一時的に動作しなくなる場合があります。

### データの扱い
この拡張は `chatgpt.com` の描画済みWebページ内容を端末内で読み取り、UI要素を識別します。会話本文を含む可能性があるDOMを処理しますが、会話内容を外部へ送信・保存しません。

- 会話内容の外部送信なし
- 会話内容の永続保存なし
- 広告・解析・テレメトリなし
- 開発者運営サーバーなし
- 設定とUI言語のみChrome Storageへローカル保存

ポップアップからプライバシーポリシーをいつでも確認できます。

### 非公式拡張
本拡張は独立した非公式プロジェクトであり、OpenAIによる作成・承認・提携製品ではありません。

拡張UIは日本語と英語に対応し、既定ではブラウザ言語を自動判定する。ポップアップから手動で言語を切り替えることもできる。

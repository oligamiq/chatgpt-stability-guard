# Chrome Web Store listing — 日本語

## タイトル
Stability Guard for ChatGPT

## 1行説明
長大なChatGPT Web会話の描画負荷を抑え、Thinking・ツールUI・code/log・古いターンを選択的に軽量化する非公式拡張。

## 詳細説明
Stability Guard for ChatGPT は、長くなったChatGPT Web会話で増えやすい描画負荷を抑えるためのブラウザ拡張です。

主な機能:
- Thinking / reasoning 表示の非表示
- MCP / tool trace本体の非表示
- Called tool 等のツール概要行の非表示
- configカード等の埋め込みツールUIの非表示
- 最新turn以外の `Failed to fetch template` アプリ読み込みエラーを非表示
- rich UI読込中プレースホルダのプリハイド
- traceの低コントラスト化・高さ制限
- code / log の画面外遅延描画
- 直近N回の対話だけ表示（任意・既定OFF、Nの既定値は3）
  - ChatGPTが会話branchや仮想スクロール構造を大きく置換した場合は、スクロール位置を強制せずそのページのrecent-Nだけ安全に解除します。ページ再読み込み後に再構築されます。
- 古い会話ターンの遅延描画（任意・既定OFF）
- 現在何件を非表示・遅延描画しているかの表示
- 各機能を個別にON/OFF

### 互換性について
この拡張は現在のChatGPT Web UIのDOM/属性構造に合わせて実装されています。ChatGPT側のサイト更新でDOMやUI構造が変わると、拡張の更新が提供されるまで検出・非表示・プレースホルダ抑制の一部または全部が一時的に動作しなくなる場合があります。

### データの扱い
この拡張は `chatgpt.com` の描画済みWebページ内容を端末内で読み取り、UI要素を識別します。会話本文を含む可能性があるDOMを処理しますが、会話内容を外部へ送信・保存しません。

- 会話内容の外部送信なし
- 会話内容の永続保存なし
- 広告・解析・テレメトリなし
- 開発者運営サーバーなし
- 設定と同意状態のみChrome Storageへローカル保存

初回有効化時に、このローカル処理を拡張UI内で説明し、明示的な同意を求めます。

### 非公式拡張
本拡張は独立した非公式プロジェクトであり、OpenAIによる作成・承認・提携製品ではありません。

拡張UIは日本語と英語に対応し、既定ではブラウザ言語を自動判定する。ポップアップから手動で言語を切り替えることもできる。

プライバシーポリシー

Stability Guard for ChatGPT · 最終更新 2026-08-15

本拡張は独立した非公式拡張であり、OpenAIによる作成・承認・提携製品ではない。

処理するデータ

chatgpt.com 上のWebサイト内容

Thinking、ツールtrace、埋め込みツールUI、プレースホルダ、code/log等を識別するため、chatgpt.com の描画済みDOMを端末内で読み取る。会話の近くや内部に存在するDOMを扱うため、処理対象にはユーザー生成コンテンツや個人的な会話内容が含まれる可能性がある。

この内容は、描画負荷を減らし、ユーザーが選択したChatGPT UI要素を非表示・遅延描画する目的に限ってブラウザ内で処理する。会話内容を拡張機能の永続ストレージへ保存せず、開発者または第三者へ送信しない。

ローカル設定

拡張設定、同意バージョン、同意時刻、UI言語設定のみを chrome.storage.local に保存する。開発者運営サーバーへ送信しない。

外部通信

解析、広告、テレメトリ、リモート設定、アカウント機能、開発者運営バックエンドを持たず、拡張自身から外部ネットワークリクエストを開始しない。

共有・販売

ユーザーデータを販売・共有・第三者移転しない。

保持・同意・削除

Webサイト内容はページ内で一時的に処理するだけで、拡張機能は保持しない。ローカル設定は変更・消去・アンインストールまでブラウザプロファイル内に残る。データ処理への同意は拡張ポップアップから取り消せる。ChatGPTタブを検出できる場合は、撤回時にそのタブを再読み込みし、撤回済み状態でDOM処理を停止する。

権限

storage はローカル設定保存に使用する。content scriptは https://chatgpt.com/* のみに限定する。

互換性

現在のChatGPT Web UIに合わせた実装である。ChatGPT側のDOM/UI更新により、拡張の更新まで一時的に検出や非表示が機能しなくなる場合がある。

連絡先

拡張機能のストア掲載ページに表示される開発者連絡先を利用する。

Privacy Policy

Stability Guard for ChatGPT · Last updated August 15, 2026

Stability Guard for ChatGPT is an independent, unofficial extension and is not created by, endorsed by, or affiliated with OpenAI.

Data handled by the extension

Website content on chatgpt.com

The extension locally reads the rendered DOM on chatgpt.com to identify Thinking displays, tool traces, embedded tool UI, placeholders, code/log blocks, and related UI. Because this DOM can appear near or inside conversations, the processed content may include user-generated content or personal communications.

This content is processed only in the browser for the extension's purpose of reducing rendering overhead and hiding or deferring selected ChatGPT UI elements. Conversation content is not persistently stored by the extension and is not transmitted to the developer or to third parties.

Local settings

Only extension settings, consent version, consent timestamp, and UI language preference are stored in chrome.storage.local. These values are not transmitted to a developer-operated server.

Network activity

The extension has no analytics, advertising, telemetry, remote configuration, account system, or developer-operated backend, and it does not initiate external network requests.

Sharing and sale

The extension does not sell, share, or transfer user data to third parties.

Retention, consent, and deletion

Website content is processed transiently in the active page and is not retained by the extension. Local settings remain in the browser profile until changed, cleared, or the extension is removed. Consent for local page processing can be revoked from the extension popup. When a ChatGPT tab can be detected, that tab is reloaded so DOM processing stops under the revoked consent state.

Permissions

The storage permission is used for local settings. Content scripts are limited to https://chatgpt.com/*.

Compatibility

The extension is built against the current ChatGPT web UI. ChatGPT DOM/UI changes can temporarily break detection or hiding until the extension is updated.

Contact

For privacy questions, use the developer contact method shown on the extension's store listing.
